Privacy Policy / 개인정보처리방침

Last updated: 2026-09-24

shorts-maker is a personal tool used only by its owner to upload videos to the owner's YouTube channel. It uses YouTube API Services. By using it you agree to the YouTube Terms of Service, and Google's handling of data is described in the Google Privacy Policy.

What it accesses

With the owner's permission (Google OAuth), the tool uploads video files, titles, descriptions and tags to the owner's channel, and reads the channel name and the status of uploaded videos. It does not access any other user's data.

Storage and sharing

The OAuth token is stored only on the owner's computer. No data is sent to any third party, sold, or used for advertising.

Revoking access

Access can be revoked at any time at https://security.google.com/settings/security/permissions.
